# Coding Standards

## General

- Follow Clean Architecture
- Use SOLID Principles
- Keep methods small
- Avoid duplicate code
- Write readable code

---

## C#

- PascalCase for Classes
- camelCase for Variables
- Async methods end with Async
- One class per file

---

## React Native

- Functional Components
- Hooks
- TypeScript
- Reusable Components
